## 🌟 Overview

Vibeside MCP is a specialized Model Context Protocol (MCP) server engineered for high-assurance vibe coding:

- **Zero-Latency Telemetry**: Direct local Chrome/Edge CDP streaming without remote cloud relays.
- **Click-to-Component Mapping**: Resolves React Fiber and Vue AST nodes directly to source files.
- **Session Persistence**: Reuses authenticated browser sessions securely.
- **Zero-Zombie Lifecycle**: Automatic background process termination on turn end.
